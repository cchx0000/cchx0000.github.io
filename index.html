02 · Common architecture

Finite structure before quotient-level readout

A recurring principle across the four completed lines is to retain source information long enough for compatibility, extension, and reconstruction to be tested before passing to compressed or global invariants.

source object → finite transport → compatible reconstruction → K / Selmer / motivic or birth-level invariant → global readout
Source visibilityKeep the original arithmetic or combinatorial object visible before compression.
Finite transportTrack exact local coordinates, extension data, and compatibility across recursive stages.
ReconstructionRequire explicit finite recovery or comparison maps rather than relying on abstract identification alone.
Global readoutOnly then extract Selmer, motivic, K-theoretic, or additive–multiplicative consequences.
